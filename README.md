# Adult — 18+ Dating MVP

A mobile-first 18+ dating and matchmaking MVP focused on compatibility, safety, and premium features.

## MVP scope
- 18+ age gate
- Landing page
- Profile creation concept
- Discovery and matching concept
- Messaging concept
- Premium membership concept
- Report/block safety controls

## Product principles
- Adults only (18+)
- Consent and user safety first
- No minors or exploitative content
- Privacy-conscious design
- Monetization through legitimate premium features

## Roadmap
1. Public landing page
2. Authentication and age verification
3. Profiles and preferences
4. Matching
5. Messaging
6. Moderation/reporting
7. Payments and premium membership
8. AI compatibility features
